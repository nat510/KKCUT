<h1 align="center">KKCUT - KKBOX 自動切歌器</h1>

<p align="center">
  在 Windows 上聽 KKBOX 時，自動切掉中國歌手的歌、簡體中文歌名的歌，以及黑名單上的歌手。
</p>

---

## 下載

到 [Releases](https://github.com/nat510/KKCUT/releases/latest) 下載免安裝版，兩個檔案擇一即可：

| 檔案 | 適用 |
| --- | --- |
| `KKCUT_x64.exe` | 64 位元 Windows（絕大多數電腦） |
| `KKCUT_x86.exe` | 32 位元 Windows |

下載後直接執行，不需要安裝。支援 Windows 10 與 Windows 11，需搭配 [KKBOX Windows 版](https://www.kkbox.com/)。

> Windows SmartScreen 可能會提示「Windows 已保護您的電腦」，因為這個程式沒有程式碼簽章。請按「其他資訊」→「仍要執行」。

## 功能

KKCUT 透過 Windows 的媒體控制讀取 KKBOX 正在播放的歌曲，符合規則就送出「下一首」。KKCUT 只在 KKBOX 換歌或暫停/播放時才被喚醒，不會定時輪詢，關掉「啟動」後完全不讀取 KKBOX。

如果切歌後 KKBOX 播的還是同一首（例如播放清單只有一首，或開了單曲循環），KKCUT 會改為暫停 KKBOX。

### 首頁

- **現在播放**：KKBOX 正在播放的歌名、歌手、專輯，以及這首歌是否會被切掉、原因是什麼。
- **啟動**：總開關。
- **中國歌手自動切歌**：歌手或樂團在中國歌手名單上就切掉。
- **簡體中文自動切歌**：歌名或專輯名是簡體中文就切掉。只有簡體字（例如「们」「说」「爱」）才算，繁簡共用的字與日文漢字不算；台灣、香港、澳門、馬來西亞、新加坡的歌手與日文歌不會因歌名被切。
- **黑名單自動切歌**：歌手在你的黑名單上就切掉。
- **作者黑名單自動切歌**：歌手在 KKCUT 作者整理的名單上就切掉。加入白名單的歌手不受影響。
- **中國歌手名單**：名單的歌手數量與更新時間。

視窗右上角的「切歌中」也是總開關：按一下變成「破防中」，暫停所有自動切歌；再按一下恢復。


### 切歌單

列出最近被切掉的歌、時間與原因。可用下拉式選單選擇記錄最近 5、15、25 或 50 首。

- **X**：刪除這筆記錄。
- **O**：把歌手加入白名單，以後不再切掉。

### 黑名單

自行輸入歌手或樂團名稱，他們的歌一律切掉（首頁「黑名單自動切歌」開啟時）。

### 白名單

自行輸入歌手或樂團名稱，他們的歌永遠不會被切，優先於所有規則。

黑名單與白名單的比對：

- 簡體與繁體視為同一個名字（「周杰伦」等於「周杰倫」）。
- 英文不分大小寫，括號裡的別名可以省略（「華晨宇 (Hua Chenyu)」輸入「華晨宇」即可）。
- 名字中的間隔號「·」可有可無（「希林娜依高」等於「希林娜依·高」）。
- 多位歌手合唱時（「A、B」「A feat. B」），任何一位符合就算。
- 同一個名字只會在其中一個名單：加入白名單會移出黑名單，反之亦然。

### 設定

- **登入時自動啟動**：登入 Windows 後在背景啟動 KKCUT，常駐於通知區域。
- **手動更新中國歌手資料**：重新從維基百科下載中國歌手名單。

## 中國歌手名單

第一次開啟 KKCUT 時會自動下載名單，之後可在「設定」手動更新。

名單取自中文維基百科的中國歌手、樂團與演唱團體分類（含子分類），並排除同時屬於台灣、香港、澳門、馬來西亞、新加坡歌手分類的人。每個名字同時以簡體與繁體儲存。維基百科要求一次只送一個請求，所以下載需要幾分鐘；下載完成前，KKCUT 只依簡體中文歌名與黑名單切歌。

## 背景執行

關閉視窗後，KKCUT 仍在通知區域（右下角）執行並繼續切歌。

- 按一下圖示：開啟視窗。
- 按右鍵：開啟 KKCUT、開關自動切歌、結束。

同一時間只會執行一個 KKCUT；再次開啟時會叫出原本的視窗。

## 資料位置

設定與記錄存在 `%APPDATA%\KKCUT`：

| 檔案 | 內容 |
| --- | --- |
| `config.ini` | 開關、黑名單、白名單、記錄數量 |
| `china-artists.json` | 中國歌手名單 |
| `skipped.txt` | 切歌記錄 |
| `kkcut.log` | 錯誤記錄 |

要完全移除 KKCUT：先在「設定」關閉「登入時自動啟動」，結束 KKCUT，再刪除 exe 與上面的資料夾。

## 自行編譯

需要 [Rust](https://www.rust-lang.org/)（1.88 以上）與 Visual Studio 的 C++ 建置工具。

```powershell
rustup target add x86_64-pc-windows-msvc i686-pc-windows-msvc
cargo build --release --target x86_64-pc-windows-msvc
cargo build --release --target i686-pc-windows-msvc
```

`tools/logo.py` 會產生 `assets` 裡的圖示（需要 Python 與 Pillow）。
